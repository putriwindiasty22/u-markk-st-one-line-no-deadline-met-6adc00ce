Entry for the [One Line, No Deadline Met](https://make.fun/c/u-markk-st-one-line-no-deadline-met-6adc00ce) bounty on [make.fun](https://make.fun): a program that writes a single-line joke excusing a missed deadline to `/output/entry.txt`.

## The entry

> My laptop died mid-sentence, and by the time the charger and I made up, the deadline had already filed for separation.

## How it works

`main.ts` writes the one-liner to `/output/entry.txt` (creating `/output` if needed). It first checks the gate itself — the line must be 1–200 characters, a single line, and not only whitespace — and refuses to write anything invalid.

Run it with Node 22+:

```sh
node main.ts
```
